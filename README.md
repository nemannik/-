# 🏍️ МотоTrail — Сайт мото-приключений

Красивый сайт-блог для публикации ваших приключений на внедорожном мотоцикле.

![Мото-приключения](https://images.unsplash.com/photo-1558981806-ec527fa84c39?w=800&q=60)

---

## 🚀 Как открыть сайт

1. Скачайте этот проект (кнопка **Code** → **Download ZIP**)
2. Распакуйте архив
3. Откройте файл **index.html** в браузере (двойной клик)

Или включите **GitHub Pages** в настройках репозитория (Settings → Pages → Source: main branch) — и сайт будет доступен по ссылке вида `https://ваш-логин.github.io/-/`

---

## ✏️ Как редактировать сайт

Вы можете редактировать файлы прямо на GitHub (нажмите на файл → карандашик ✏️) или скачать и открыть в любом текстовом редакторе.

### 📝 Добавить новое приключение

Откройте файл **index.html** и найдите раздел `ПРИКЛЮЧЕНИЯ`. Скопируйте блок:

```html
<article class="adventure-card fade-in">
  <img class="card-image"
       src="ССЫЛКА_НА_ФОТО"
       alt="Описание фото">
  <div class="card-body">
    <div class="card-date">ДАТА (например: 15 апреля 2026)</div>
    <h3 class="card-title">ЗАГОЛОВОК ПРИКЛЮЧЕНИЯ</h3>
    <p class="card-text">
      ОПИСАНИЕ — напишите здесь что произошло, где были, что видели.
    </p>
    <a href="#" class="card-link">Читать далее →</a>
  </div>
</article>
```

Вставьте его **перед** закрывающим `</div>` секции приключений и заполните своими данными.

### 📸 Добавить фото в галерею

Найдите раздел `ГАЛЕРЕЯ` в **index.html** и добавьте блок:

```html
<div class="gallery-item fade-in" onclick="openLightbox(this)">
  <img src="ССЫЛКА_НА_ФОТО" alt="Описание">
  <div class="gallery-overlay"><span>Подпись к фото</span></div>
</div>
```

### 🏍️ Изменить информацию о мотоцикле

Найдите раздел `МОЙ МОТОЦИКЛ` в **index.html** и измените название, объём, мощность и другие характеристики.

### 👤 Изменить информацию «Обо мне»

Найдите раздел `О СЕБЕ` в **index.html** и измените:
- Ссылку на фото (`src="..."`)
- Имя и описание
- Статистику (км, поездки, опыт)

### 🔗 Добавить ссылки на соцсети

В подвале сайта (раздел `ПОДВАЛ САЙТА`) замените `#` на ваши ссылки на YouTube, Telegram, Instagram и ВКонтакте.

### 🎨 Изменить цвета сайта

Откройте файл **styles.css** и в самом начале найдите раздел `:root`. Там можно изменить:
- `--color-accent` — основной яркий цвет (по умолчанию оранжевый `#e87a1e`)
- `--color-bg` — цвет фона
- `--color-text` — цвет текста

### 🖼️ Как загрузить свои фотографии

1. Загрузите фото в папку проекта (например, создайте папку `photos/`)
2. В HTML замените ссылку: `src="photos/мое-фото.jpg"`
3. Или используйте бесплатные хостинги для фото:
   - [ImgBB](https://imgbb.com/)
   - [Postimages](https://postimages.org/)

## 💡 Советы

- Все изменения сразу видны — просто обновите страницу в браузере (F5)
- Сайт адаптивный — красиво выглядит и на телефоне, и на компьютере
- Фотографии лучше загружать размером не более 1920px по ширине для быстрой загрузки
- Комментарии в HTML (текст между `<!--` и `-->`) не видны на сайте — они только для вашего удобства
